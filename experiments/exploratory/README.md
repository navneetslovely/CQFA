# Exploratory studies

These studies report no result in the paper or the supplementary document. They
are included so that every experiment written for this project is present.

| directory | what it studies |
|---|---|
| `readout_dial/` | the frame-register reduced state and its circulant structure |
| `novelty_gate/` | a learned reduction of the frame register |
| `trifecta/` | combining trainability, hardness and separation in one construction |
| `fusion/` | a unified statement across the advantage arms |
| `copy_fusion/` | copy permutation as the group action, and an informed comparator |

Their recorded outputs are under `results/readout_dial/`, `results/novelty_gate/`,
`results/trifecta/`, `results/fusion/` and `results/copy_fusion/`.

Nothing in this directory is cited by either document, and no claim depends on
these files.
